CapybarApp started as a completely different project called CapybarIA, a dashboard for tracking AI-related data. I eventually dropped the original concept because of the cost of maintaining its data sources and turned it into a cryptocurrency dashboard instead.

I handled the design and development of both projects myself, using React for the frontend.

## CapybarIA

The original idea was to bring different AI-related metrics into a single dashboard. It included the combined market capitalization of AI companies, rankings of open-source language models, GitHub developer activity, and other statistics.

I built the interface with React and used ECharts to display the data.

The main problem was the data. Most of the metrics relied on external APIs, and keeping everything updated was getting expensive. Rather than continue paying for those services, I decided to reuse the project for something else.

## CapybarApp

CapybarApp kept the dashboard concept but switched its focus to cryptocurrencies.

I redesigned the interface around crypto market data and built several features, including:

- A live ranking of the top 100 cryptocurrencies
- A heatmap showing cryptocurrency market performance
- Halving countdowns for different cryptocurrencies

The frontend was built with React, with charting libraries used for the data visualizations. I worked on everything from the layout and components to the overall visual design.

The goal was to keep the interface simple and make market information easy to read without cramming too much data onto the screen.

CapybarApp ended up being a more focused version of the original project, with a different set of features and fewer dependencies on expensive data sources.
