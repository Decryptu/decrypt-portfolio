# gen2recomp

![Temporary gen2recomp project visual](/images/gen2recomp-home.webp)

gen2recomp is a work-in-progress native reimplementation of the Generation 2
Game Boy Color games, built from scratch in Godot 4 and GDScript.

The actual recomp project is still in development and does not have a finished
in-game UI yet. These visuals are temporary illustrations included while the
first real screenshots are being prepared.

![Temporary gen2recomp cartridge visual](/images/gen2recomp-cartridges.webp)

## Focus

- **Game development:** Building a native experience in Godot 4 and GDScript.
- **Engine development:** Creating the technical foundation for the
  reimplementation from scratch.
- **Data systems:** Verifying, importing and decoding cartridge data into a
  local asset pipeline.

The project is coming soon, with the Godot recomp taking priority over the
temporary visual material shown here.
